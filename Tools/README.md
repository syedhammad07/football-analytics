# 🛠️ Tools

Interactive pages built on the data from the projects in this repo. Each one is a single HTML file that runs in the browser with no server.

| Tool | What it does |
| --- | --- |
| [**Midfield Matchup**](Midfield-Matchup/) | Compare any two Premier League midfielder seasons (1992/93 to 2025/26) stat by stat, and find the players who played most like them. [Open it](https://syedhammad07.github.io/football-analytics/Tools/Midfield-Matchup/). |
