# 🛠️ Tools

Tools built on the data from the projects in this repo: interactive pages that run in the browser, and command-line tools you run with Python.

| Tool | What it does |
| --- | --- |
| [**Midfield Matchup (Premier League Edition)**](Midfield-Matchup/) | Compare two to four Premier League midfielders (1992/93 to now, updated weekly), season by season or whole careers, stat by stat, and find the players who played most like them. [Open it](https://syedhammad07.github.io/football-analytics/Tools/Midfield-Matchup/). |
| [**Scout Finder**](Scout-Finder/) | Find Premier League players who play like someone else, for less: a Python command-line tool that ranks every 2025/26 player by how closely his numbers match a target, with Transfermarkt values. `find "Rodri" --max-age 25 --max-value 40` → Nico González, Lewis Miley. |
