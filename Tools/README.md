# 🛠️ Tools

Tools built on the data from the projects in this repo: interactive pages that run in the browser, and command-line tools you run with Python.

| Tool | What it does |
| --- | --- |
| [**Midfield Matchup (Premier League Edition)**](Midfield-Matchup/) | Compare two to four Premier League midfielders (1992/93 to now, updated weekly), season by season or whole careers, stat by stat, and find the players who played most like them. [Open it](https://syedhammad07.github.io/football-analytics/Tools/Midfield-Matchup/). |
| [**Player Style Finder**](Player-Style-Finder/) | Find footballers who play alike, and see why. 1,350 players (99 goalkeepers) from the Premier League, La Liga, Serie A and Ligue 1 in 2015/16, built from StatsBomb event data with PCA, nearest neighbours and k-means roles. Player fingerprints, explained matches, radar comparisons, replacements, 13 style roles, team styles and a role map. [Open it](https://syedhammad07.github.io/football-analytics/Tools/Player-Style-Finder/). |
| [**Scout Finder**](Scout-Finder/) | Find players who play like someone else, for less. Two modes: the Premier League on official stats (2025/26 and this season so far), or all of Europe's top five leagues (2,474 players, 2025/26). Pick a player, filter by age, price and league, and get the closest matches with Transfermarkt values, clubs as of the summer 2026 window and a radar of all 27 stats. [Open it](https://syedhammad07.github.io/football-analytics/Tools/Scout-Finder/). Also a Python command-line tool: `find "Rodri" --top5 --max-age 25 --max-value 40` → Nico González, Ezequiel Fernández. |
