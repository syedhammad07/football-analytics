# Notebooks

Run from this project folder after the one-time setup in the [main README](../../../README.md#setup). Each notebook is generated by the `build_*.py` script next to it (so the code is easy to review), then executed.

| Notebook | Question | Charts |
| --- | --- | --- |
| [`01_how_chelsea_won.ipynb`](01_how_chelsea_won.ipynb) | Best team or luckiest? What did the 3–4–3 change? How did 10th become 1st? | 01–08 |
| [`02_players_and_style.ipynb`](02_players_and_style.ipynb) | Players vs the league, finishing, signings, Kanté, team style, Conte's formations | 09–16 |
| [`03_managers_and_signings.ipynb`](03_managers_and_signings.ipynb) | How did Conte's Chelsea differ from Mourinho's and Hiddink's? How did each signing change, and how did they compare with the players they replaced? | 17–19 |
| [`04_the_men_already_there.ipynb`](04_the_men_already_there.ipynb) | Which players already at Chelsea went up a level under Conte, and how? | 20–21 |

`setup_cell.py` holds the first code cell shared by all four notebooks (paths, chart style, data loaders, the expected-points simulation).

```bash
python notebooks/build_01_how_they_won.py && python notebooks/build_02_players_and_style.py && python notebooks/build_03_managers_and_signings.py && python notebooks/build_04_the_men_already_there.py
jupyter nbconvert --to notebook --execute --inplace notebooks/0*.ipynb
```
