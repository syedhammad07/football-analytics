Run them in order after downloading and cleaning the data (see the [main README](../README.md#how-to-run)).

## How the notebooks are made

Each notebook is generated by the `build_XX_*.py` script next to it, then executed:

```bash
python notebooks/build_07_leaderboards.py
cd notebooks && jupyter nbconvert --to notebook --execute --inplace 07_league_leaderboards.ipynb
```

Keeping the code in plain `.py` files makes changes easy to review in Git. The notebooks hold the outputs.
